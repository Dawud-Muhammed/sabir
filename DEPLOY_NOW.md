## Three Simple Steps

### Step 1: Create GitHub Repository
Go to https://github.com/new
- Name: `sabir`
- Description: `SABIR - Premium Islamic focus application`
- Visibility: **Public** (important!)
- Click "Create repository"

### Step 2: Copy Your Repository URL
From your new GitHub repository, copy the URL (looks like):
```
https://github.com/YOUR-USERNAME/sabir.git
```

### Step 3: Run These Commands
Replace `YOUR-USERNAME` with your GitHub username:

```bash
cd d:\Projects\sabir

git remote add origin https://github.com/YOUR-USERNAME/sabir.git
git branch -M main
git push -u origin main
```
